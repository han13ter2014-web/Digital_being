# Digital Being v0.1.0

Первый публичный исследовательский релиз Digital Being.

## Что внутри

- Core с состоянием, памятью, намерениями и занятиями;
- Delamain/Effector с sandbox и approval;
- Tk-интерфейс «Сейчас», «Карта жизни», «Дневник», «Занятия»;
- приёмочный жизненный цикл Core → approval → действие → память;
- документация для пользователя, разработчика, AI-помощника и самой жизни;
- жизненный контур без Ollama, DeepSeek и других LLM.

## Установка

1. Скачайте `DigitalBeing_Setup_v0.1.0.exe`.
2. Запустите установщик.
3. Выберите ярлыки и автозапуск при необходимости.
4. После установки запустите Digital Being из меню Пуск или с рабочего стола.

Установщик предназначен для Windows. Он не подписан коммерческим сертификатом,
поэтому SmartScreen может показать предупреждение о неизвестном издателе.
