✅ 1. ДОЛГОСРОЧНАЯ ПАМЯТЬ С DECAY-ФУНКЦИЕЙ
   📁 Файл: src/memory/long_term_memory.py

   Особенности:
   • Экспоненциальный decay воспоминаний (забывание со временем)
   • Двухуровневая память: краткосрочная (100-200) → долгосрочная (консолидированная)
   • Три типа памяти: эпизодическая, семантическая, процедурная
   • Ассоциативные связи между воспоминаниями (граф памяти)
   • Запрос с релевантностью и силой воспоминания
   • Автоматическая консолидация важных воспоминаний

   Параметры:
   - decay_rate = 0.95 (потеря 5% силы за цикл)
   - consolidation_threshold = 0.7 (порог консолидации)
   - importance модифицирует скорость забывания
   - access_count усиливает память

   Использование:
   ```python
   memory = LongTermMemory("Agent")
   memory.store(content="факт", importance=0.8)
   results = memory.recall("запрос", threshold=0.1)
   memory.trigger_decay()
   ```

✅ 2. МНОГОЗАДАЧНОСТЬ ЦЕЛЕЙ
   📁 Файл: src/cognition/multi_goal_manager.py

   Особенности:
   • Параллельное управление N активными целями (по умолчанию 3)
   • Состояния целей: PENDING → ACTIVE → PAUSED/BLOCKED → COMPLETED
   • Приоритизация (1-5, где 5=критическая)
   • Зависимости между целями (одна блокирует другую)
   • Отслеживание эффективности (cycles_per_percent)
   • Циклическое распределение энергии между целями
   • История прерываний (interruptions)

   Алгоритм выбора целей:
   1. Активируются новые цели если есть место
   2. Сортируются по приоритету и времени затраченному
   3. Берется топ-N целей для работы

   Использование:
   ```python
   manager = MultiTaskGoalManager(max_active_goals=3)
   goal = manager.add_goal("Цель", difficulty=2, priority=3)
   active = manager.select_goals_for_cycle(available_energy=100)
   manager.update_goal_progress(goal_id, progress_delta)
   manager.complete_goal(goal_id)
   ```

✅ 3. КООПЕРАЦИЯ МЕЖДУ АГЕНТАМИ
   📁 Файл: src/cognition/agent_cooperation.py

   Особенности:
   • Глобальный хаб кооперации (singleton pattern)
   • Типы сообщений: REQUEST, RESPONSE, SHARE_KNOWLEDGE, COLLABORATE, QUERY, FEEDBACK
   • Общая база знаний по темам (shared_knowledge_base)
   • Репутационная система между агентами (0.0-1.0)
   • Группы сотрудничества (N агентов работают вместе)
   • Приоритизированная очередь сообщений
   • История всех взаимодействий

   Репутация:
   - Начальная: 0.5 (нейтральная)
   - +0.1 за каждое успешное взаимодействие
   - Используется для выбора надежных источников

   Использование:
   ```python
   cooperation_hub.register_agent(agent)
   cooperation_hub.send_message(from_id, to_id, message_type, content)
   messages = cooperation_hub.get_pending_messages(agent_id)
   result = cooperation_hub.query_knowledge(agent_id, topic)
   stats = cooperation_hub.get_agent_statistics(agent_id)
   ```

✅ 4. САМОЭВОЛЮЦИЯ И САМОУЛУЧШЕНИЕ
   📁 Файл: src/evolution/self_evolution_analyzer.py

   Особенности:
   • Анализ 5 метрик производительности:
     - energy_efficiency (энергия / результаты)
     - goal_completion_rate (завершение целей)
     - learning_speed (концепции / циклы)
     - memory_efficiency (качественные концепции / всего)
     - concepts_quality (средняя уверенность)
   • Идентификация bottlenecks (узких мест)
   • Генерация код-предложений с оценкой impact
   • Безопасное применение модификаций
   • История всех эволюционных шагов

   Типы модификаций:
   - parameter_adjustment: изменение параметров
   - enable_feature: включение/отключение фич

   Использование:
   ```python
   analyzer = SelfEvolutionAnalyzer(agent)
   performance = analyzer.analyze_performance()
   improvements = analyzer.identify_improvements()
   suggestion = analyzer.generate_code_suggestion(improvement)
   analyzer.apply_self_modification(suggestion)
   report = analyzer.generate_self_report()
   ```

   - Интегрирует в свою память
   - Повышает репутацию других
   - Результат: коллективный интеллект

4️⃣ САМОУЛУЧШЕНИЕ (через анализ)
   - Периодический анализ производительности
   - Идентификация проблем
   - Применение оптимизаций
   - Результат: скор производительности растет
