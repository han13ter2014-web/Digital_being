# Система рефлексии и самоанализа агента

## 📚 Обзор

Система рефлексии позволяет агенту анализировать собственную производительность, выявлять закономерности в поведении и адаптировать стратегию обучения.

## 🎯 Основные возможности

### 1. **Отслеживание метрик производительности**
- Процент успешных действий
- Скорость обучения (знаний/цикл)
- Темп завершения целей
- Динамика изменения энергии и интеллекта

### 2. **Выявление закономерностей**
- **Стабильный рост**: Интеллект растёт линейно
- **Плато (застой)**: Развитие прекратилось, нужен новый подход
- **Истощение энергии**: Энергия быстро падает
- **Ускорено обучение**: Интенсивное накопление знаний

### 3. **Генерация выводов**
- Оценка эффективности текущей стратегии
- Рекомендации по оптимизации
- Предложения по изменению целей

### 4. **Стратегические рекомендации**
- Приоритизированные рекомендации (высокий/средний)
- Обоснование каждой рекомендации
- Адаптивность к уровню развития агента

## 📖 Использование

### Базовая рефлексия

```python
from src.core.agent import DigitalBeing

agent = DigitalBeing("MyAgent")

# После выполнения нескольких циклов
reflection = agent.reflect()

print(reflection['patterns'])    # Обнаруженные паттерны
print(reflection['insights'])    # Выводы
print(reflection['metrics'])     # Метрики производительности
```

### Полный отчёт самоанализа

```python
# Генерирует и сохраняет полный отчёт
report = agent.generate_self_analysis_report()

# Отчёт содержит:
# - текущие метрики
# - эффективность
# - выявленные паттерны
# - выводы
# - стратегические рекомендации
```

### Получение метрик производительности

```python
metrics = agent.get_performance_metrics()

print(metrics['success_rate'])          # % успешных действий
print(metrics['learning_speed'])        # знаний/цикл
print(metrics['goal_completion_rate'])  # целей/цикл
print(metrics['knowledge_growth_rate']) # рост знаний/цикл
print(metrics['current_intelligence'])  # текущий уровень
print(metrics['knowledge_size'])        # размер БЗ
```

## 🔧 Интеграция в цикл агента

В файле `main.py` рефлексия выполняется каждые 3 цикла:

```python
# Рефлексия каждые 3 цикла
if (i + 1) % 3 == 0:
    print(f"💭 РЕФЛЕКСИЯ АГЕНТА")
    reflection = agent.reflect()
    if reflection['patterns']:
        print("🔄 Обнаруженные паттерны:")
        for pattern in reflection['patterns']:
            print(f"  • {pattern['description']}")
```

Полный отчёт генерируется в конце всей симуляции.

## 🎨 Классы и методы

### ReflectionEngine

#### Основные методы:

- **`record_cycle(agent_state)`** - Записывает метрики цикла
- **`analyze_performance(window_size=10)`** - Анализирует последние N циклов
- **`identify_patterns()`** - Выявляет закономерности
- **`generate_insights()`** - Генерирует выводы
- **`suggest_strategy_adjustments(current_intelligence)`** - Рекомендует изменения
- **`generate_report(agent_state)`** - Создаёт полный отчёт
- **`save_reflection_report(report)`** - Сохраняет отчёт в JSON
- **`reflect()`** - Главный метод анализа

### DigitalBeing (расширения)

- **`reflect()`** - Вызывает анализ производительности
- **`generate_self_analysis_report()`** - Создаёт и выводит полный отчёт
- **`get_performance_metrics()`** - Возвращает текущие метрики

## 📁 Хранение данных

Отчёты сохраняются в: `data/logs/reflection_report.json`

Каждый запуск добавляет новый отчёт в список, позволяя отслеживать развитие агента во времени.

## 🚀 Расширение системы

Для добавления новых типов анализа:

1. Добавьте метод в `ReflectionEngine`
2. Вызовите его в методе `reflect()`
3. Включите результаты в отчёт

Пример добавления нового паттерна:


## 📈 Метрики, отслеживаемые системой

| Метрика | Описание | Ед. изм. |
|---------|----------|---------|
| success_rate | % успешных действий | % |
| learning_speed | Скорость накопления знаний | факты/цикл |
| goal_completion_rate | Темп завершения целей | цели/цикл |
| knowledge_growth_rate | Рост базы знаний | записи/цикл |
| avg_intelligence_growth | Средний рост интеллекта | уровни/цикл |
| avg_energy | Средняя энергия | единицы |
| efficiency | Общая эффективность обучения | баллы |
