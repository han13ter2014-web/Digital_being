# Добавлена система рефлексии для самоэволюционирующегося агента

## 🎯 Что было добавлено

### 1. Новый модуль: `src/cognition/reflection_engine.py`
Полнофункциональный движок рефлексии с поддержкой:

- **ReflectionEngine класс** - основной компонент для анализа
- **Отслеживание метрик** - история производительности по циклам
- **Анализ паттернов** - выявление тенденций (рост, плато, истощение)
- **Генерация выводов** - автоматические рекомендации
- **Стратегические предложения** - приоритизированные рекомендации

### 2. Интеграция с агентом (`src/core/agent.py`)
Новые методы в классе `DigitalBeing`:

```python
# Быстрый анализ
agent.reflect()  # возвращает паттерны, выводы и метрики

# Полный отчёт с сохранением
agent.generate_self_analysis_report()

# Получить метрики
agent.get_performance_metrics()
```

### 3. Обновлён главный цикл (`main.py`)
- Рефлексия выполняется каждые 3 цикла
- Финальный отчёт с метриками производительности
- Сохранение отчётов в `data/logs/reflection_report.json`

### 4. Примеры использования (`examples_reflection.py`)
3 примера:
1. Базовый анализ производительности
2. Стратегические рекомендации
3. Долгосрочная рефлексия

## 📊 Отслеживаемые метрики

| Метрика | Значение |
|---------|----------|
| **Успешность** | % успешных действий |
| **Скорость обучения** | фактов/цикл |
| **Завершение целей** | целей/цикл |
| **Рост знаний** | записи/цикл |
| **Эффективность** | интегральная оценка |

## 🔍 Выявляемые паттерны

1. **Стабильный рост** - предсказуемое развитие
2. **Плато** - застой в развитии (требует вмешательства)
3. **Истощение энергии** - неэффективное использование ресурсов
4. **Ускоренное обучение** - интенсивное накопление знаний

## 💡 Рекомендации системы

- Снизить/повысить сложность задач
- Расширить/оптимизировать источники знаний
- Адаптировать стратегию к уровню развития
- Переквалифицировать подход при обнаружении плато

## 🚀 Быстрый старт

```python
# 1. Запустить основной агент
python main.py

# 2. Запустить примеры
python examples_reflection.py

# 3. Проверить отчёты
cat data/logs/reflection_report.json
```
