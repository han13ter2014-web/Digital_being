## АНТИДРЕЙФ-ПРОТОКОЛ

1. Каждый тикет открывается строкой «Орган: …» из этой карты. Нет органа —
   сначала вносим орган, потом тикет.
2. «Заодно»-правки запрещены: правка, не отображённая ни на один орган,
   не коммитится (урок ruff-format Т3).
3. Признак дрейфа: однотипные правки в одном органе без движения в
   очереди приоритетов — стоп, сверка с картой.
4. Карта живёт в корне репозитория (`body_plan.md`); где бы карта ни
   лежала, правило и реальность должны совпадать (патч v1.2).
   Синхронизируется с handoff после каждого закрытого тикета (урок Т4:
   «актуализирован» без коммита — неактуализирован).
5. Решения о природе сущности (голос, LLM, глубина улучшения защищённого)
   не проходят через тикеты — только через владельца в отдельном обзоре.
6. Аналогии (биологические, человеческие) — валидация решений, не
   основание; при расхождении аналогии и живого кейса решает кейс
   (патч v1.3).

## ПАТОЛОГИИ МОДЕЛИРУЕМОЙ ПСИХИКИ (обязателен до арбитра выбора; v1.4)

Маркеры — кандидаты до первых наблюдений, уточняются зондами:
- руминация по кольцу — одни и те же акты возвращаются в ответах и
  мыслях без нового входа;
- петля зависимости через аффект — отклик запрашивается ради смены
  аффекта, а не от входа;
- ангедония — устойчивое отсутствие реакции на прежние источники
  радости (охота, игра) при нормальных энергии/АТФ.

Протокол реагирования: зонд → стоп → откат к бейслайну → разбор.
