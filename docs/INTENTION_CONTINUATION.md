# Продолжение конкретной выбранной попытки

Из ограниченной истории предлагается кандидат intention_continuation для
explore/decomposition/synthesis/ask_user с прежней темой и причиной.
Это попытка без наблюдаемого эффекта, interrupted, denied, error или
unobserved; более поздний observed effect для той же пары способ/тема
закрывает раннюю запись. Отдых и другие темы её не стирают. Текущий цикл
не повторяется. Застрявший способ не возобновляется без существующего
механизма разрешения; availability/stop и общий арбитр сохраняются.

Сила 0,4 — эвристика, не обязательный приоритет. Новая запись содержит
continuation_of, связывающий её с прошлой попыткой. Это не новая очередь
целей и не полный менеджер намерений. Отдельных cancel/abandon/reconsider
пока нет; намерение может исчезнуть при вытеснении из окна 200 записей.
«Эффект» пока WorldDelta: он не гарантирует достижения цели и может
преждевременно закрыть продолжение из-за регистрации нового опыта.
Эти границы требуют следующего измерения, не подмены критерия ради тестов.

Тесты test_intention_continuation.py: отдых не стирает тему/причину,
кандидат может проиграть отдыху и позже выполнить именно прежнюю тему,
checkpoint сохраняет связь, защита от тупика не обходится. Арбитр в
интеграционном выборе контролируется: естественная частота возвратов пока
не измерена. Профильный набор continuation/history/profile/stop: 13 passed
до добавления отдельного restore-теста; расширенный профильный набор — 21 passed.
Общий прогон механизма: 1249 passed, 2 skipped, без benchmarks.

## Естественный замер: гипотеза не подтвердилась

Три зерна × 1000 тиков, обычный раннер/арбитр, офлайн, 5 секунд
регенерации на шаг, штатное сохранение/запуск после 500-го. Контроль:
тот же код с --no-continuation, отключён только генератор возврата.

```powershell
python tools/manual/autonomous_life_measure.py --cycles 1000 --seed 1 --report after.json
python tools/manual/autonomous_life_measure.py --cycles 1000 --seed 1 --no-continuation --report before.json
```

Во всех трёх парах: **0 предложений, 0 выборов продолжения**.
Продуктивные действия/эффекты до и после совпали: 126/36, 112/27, 117/28.
История намерений, память, энергия, усталость и кулдаун восстановились
одинаково. Это не строго детерминированная гарантия: wall-clock источники
случайности/кулдаунов не унифицированы, но в данном запуске метрики совпали.

Диагностический прогон 300 тиков, зерно 1: 21 запись с темой. Explore/
exploration и ask_question имели had_effect=true, в том числе за простую
регистрацию опыта. Нерезультативные тематические записи были reflection,
который не входит в набор продолжаемых способов. Таким образом, критерий
наблюдаемого эффекта преждевременно закрывает исследовательскую попытку.

**Вывод:** компонент проводки проверен, но устойчивость намерений в
естественной жизни НЕ показана. Не поднимать силу кандидата и не объявлять
нулевые возвраты успехом. Следующий необходимый контракт — отдельно
ожидаемый результат/критерий удовлетворения намерения, факт исполнения,
новое свидетельство и явное решение продолжить/отложить/завершить.
Без него система не знает, закончилось ли дело, даже если мир изменился.
Измеритель сохраняет continuation_offers/choices/losses/traces и конечное
окно истории для проверки этого вывода.
