# Live-smoke 9D-1 — ручной Telegram private sandbox

Дата: 2026-11-18.

## Разрешение и изоляция

Владелец отдельно явно разрешил ограниченный live-smoke и подтвердил точную редакцию исходящего ответа перед отправкой. Использовались отдельный тестовый Telegram-бот и личный чат владельца.

Рабочие данные изолированы в `tmp/telegram_live_smoke/`; живой проектный `data/` не читался и не изменялся. Token загружался из существующего credential backend и не записывался в состояние sandbox, команды, отчёт или вывод. Credential не удалялся после проверки.

## Фактическая последовательность

1. `getMe` подтвердил валидность bot credential. Первый `getUpdates` не обнаружил личной текстовой реплики.
2. Sanitized-диагностика показала пустую очередь и отсутствие webhook. Владелец повторно отправил тестовое личное сообщение.
3. Успешный receive-path выполнил один `getMe`, один предварительный bounded `getUpdates` для определения private scope и один bounded `getUpdates` через `SocialChannelManager.receive`.
4. В карантин принята **1** реплика как `external_social_claim`; дубликатов **0**, ignored в успешном batch **0**. Автоматического ответа не было.
5. Владелец подтвердил точную подготовленную редакцию. Перед approval включён независимый reply grant; после этого выполнена новая approval точного текста и актуальной grant version.
6. Выполнен **1** `sendMessage` с `reply_parameters` и `allow_sending_without_reply=false`. Telegram receipt совпал по bot/account, private chat, точному тексту и локальному контексту. Статус: **sent**.
7. Автоматических retry: **0**. Повторной отправки, polling worker, webhook, автономного resume и публичных действий не было.

Всего в ходе разрешённой live-проверки выполнено **8** вызовов фиксированного HTTPS Telegram Bot API: **4** в успешном receive/send path и **4** в начальной диагностике пустой очереди. Другие внешние сервисы не вызывались.

## Результат и граница

| Проверка | Результат |
| --- | --- |
| Реальный credential и bot identity | Подтверждены без раскрытия секрета |
| Ручной private receive | **1** реплика в карантине |
| Owner-approved exact send | **1** отправка |
| Receipt | Совпал, доставка засчитана |
| Автономные ответы и retry | **0** |
| Доступ к живому `data/` | Не использовался |
| Secret в checkpoint/report/output | Не обнаружен |

Это подтверждает только минимальный реальный private receive/send path для одного тестового бота и одного личного диалога. Нагрузка, группы, медиа, массовые рассылки, автономный обмен и длительная эксплуатация не проверялись.

Отчёт sanitized: внешние идентификаторы, содержимое входящих и исходящих реплик, token и URL с credential не включены.

Commit и push не выполнялись.
