# От понятия к отдельному проверяемому утверждению

Понятие не равно одному факту: результат об энергии не подтверждает и не
опровергает результат об усталости. Добавлен `MentalModel.claims`, отдельный
от графа понятий набор утверждений. Каждое хранит subject, metric, relation,
conditions и собственные свидетельства с происхождением.

Вывод содержит отдельно направление, уверенность и статус:
`insufficient`, `supported`, `refuted`. Статус — текущий вывод в рамках
условий и эвристической модели, не доказательство универсальной истинности.

Первый потребитель — уже выбранный отдых. До действия фиксируются ожидания
роста энергии ниже потолка и снижения усталости выше нуля; после записываются
раздельные наблюдения. На потолке энергии нельзя проверить её рост, но можно
проверить снижение усталости. Нет тела/валидного измерения — нет свидетельства
об усталости. Арбитр не обязан выбирать эксперимент.

## Совместимость

Старый точный узел «телесный опыт: rest повышает энергию ниже потолка»
копируется в соответствующее утверждение с сохранением происхождения.
Из общих понятий, текста определения и эмоций свидетельства не выводятся.
Старый узел временно продолжает обновляться для совместимости прежних
потребителей и измерителей; канонические раздельные выводы — `model.claims`.
Это технический переход, не два независимых источника свидетельств:
источники имеют тот же id действия. Старый граф не суммируется с claims.

Утверждения входят в полный экспорт модели, чекпоинт и наследование семени.
Вопрос о наследовании телесных выводов ребёнком с другим устройством требует
отдельной политики: условия пока задаются лишь для действия и границ шкалы,
а не для версии тела. Переиспользование таких выводов не означает их
универсальной применимости к иному телу.

## Замер

```powershell
$env:PYTHONIOENCODING='utf-8'
python tools/manual/claim_measure.py --report claims.json
python -m pytest -q tests/test_empirical_claims.py
```

Один реальный `act('rest')`, энергия 20, усталость 0,8. Восстановление энергии
контролируемо подменено на нулевое; шаг тела не подменён.

| Результат | До разделения | После |
|---|---|---|
| Δ энергии = 0 | отрицательное свидетельство в старом узле | energy: refuted, направление −1 |
| Усталость 0,8 → 0,754 | не записывалась как отдельное утверждение | fatigue: supported, направление +1 |
| Уверенность каждого вывода | только энергия | 0,433 для каждого отдельно |
| Сохранение и обычный запуск | только прежний узел | оба утверждения идентичны |
| Следующее ожидание | только энергия: −1 | энергия: −1, снижение усталости: +1 |

## Границы

Типы утверждений и первичная гипотеза заданы разработчиком. Свободное
формулирование проверок и выбор эксперимента ещё не реализованы. Направление
определяется наблюдаемой разницей, без контроля всех внешних причин: это
локальное свидетельство перехода состояния после действия, не строгий
каузальный эксперимент. Не реализованы отдельные утверждения для всех
понятий, забывание/пересмотр условий и версия тела. Поведение прочих понятий
не переинтерпретировано.
