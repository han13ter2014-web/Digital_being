# Проверка представления как необязательный кандидат выбора

`propose_experiment()` рассматривает только существующие утверждения о
собственном отдыхе. Не создаёт цель, не выполняет действие и не переписывает
желания. Кандидат `self_experiment` поступает обычному арбитру до фильтра
доступности; последующая петля выхода из тупика также может его заменить.

Условия предложения:

- есть собственное утверждение с уверенностью ниже 0,7;
- сейчас можно проверить нужное свойство: энергия ниже потолка либо
  усталость выше нуля;
- после последней выбранной проверки прошло минимум 20 циклов.

Уверенное опровержение тоже завершает проверку: система не пытается
добиваться «правильного» положительного результата. Сила кандидата ограничена
0,55 и зависит от неопределённости. Это эвристика инициативы, а не измеренный
информационный выигрыш. После выбора действие выполняется обычным act(),
который уже фиксирует ожидание и наблюдение. Результат тика содержит
experiment_proposal / experiment_result с id утверждения. Кулдаун сохраняется
в чекпоинте и не сбрасывается при обычном перезапуске.

## Контроль до/после

```powershell
python tools/manual/experiment_choice_measure.py --report choice.json
python -m pytest -q tests/test_experiment_proposals.py
```

Настоящий choose_action арбитра, одинаковый контролируемый вердикт его
голосов. До — только другое побуждение, после — добавлен кандидат проверки:

| Сила другого побуждения | До | После |
|---|---|---|
| 0,1 | другое побуждение | собственная проверка |
| 1,0 | другое побуждение | другое побуждение |

После трёх опровержений уверенность в отрицательном выводе 0,9; кандидат
больше не предлагается. На потолке энергии проверка роста не предлагается.
Отдельный интеграционный тест проходит autonomous_tick → арбитр → act →
наблюдение → изменение утверждения и кулдаун.

## Границы

Тест выбора не доказывает спонтанность или свободу воли: внутренние вердикты
контролируются, чтобы изолировать конкуренцию кандидатов. Длинная траектория
с естественными желаниями ещё не измерена. Гипотезы ограничены отдыхом,
сила и кулдаун заданы разработчиком; свободное порождение экспериментов и
причинное обоснование вмешательства ещё отсутствуют. Проверка отдыхом
безопасна для уже существующего тела; общий исполнитель произвольных
экспериментов здесь намеренно не добавлен.
