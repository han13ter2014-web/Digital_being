# Непрерывность собственного опыта при перезапуске

## Найденные разрывы

1. Обычный `create_agent()` восстанавливал тело и счётчики из чекпоинта,
   но переживания оставались в отдельном файле, который не загружался.
2. Сохранение раннера при остановке вызывало интервальный `save_state()`:
   при отсутствии эволюции и вне интервала сохранение могло быть пропущено.
3. Чекпоинт записывался напрямую, а старые файлы удалялись до завершения
   записи: сбой мог повредить последнюю доступную точку восстановления.

## Исправление

Полная ментальная модель включена в тот же чекпоинт, что энергия, состояние
тела и цикл. При восстановлении модель наполняется без замены самого объекта:
ссылки подсистем (включая SleepCycle) остаются действительны. Данные узлов
сначала разбираются целиком: ошибка разбора секции не оставляет частично
подменённую память. Незавершённые ожидания сбрасываются; новое ожидание
строится из наблюдений, а не из намерения выполнить действие.

`save_state(force=True)` обходит интервальную оптимизацию. Этот путь
используют сохранение раннера и завершение в main.py. Обычные периодические
вызовы сохраняют прежнее поведение. Учитывается checkpoint_dir агента.

JSON и gzip пишутся во временный файл рядом с целевым, затем публикуются
через `os.replace`. Прунинг происходит после успешной публикации. На ошибке
временный файл удаляется, прежний чекпоинт не уничтожается. Это защита от
частичной записи процесса; гарантию переживания потери питания не заявляем.

`load_state()` возвращает результат восстановления; старт не сообщает
«восстановлен из чекпоинта», когда применение состояния завершилось ошибкой.

## Совместимость и границы

Поле `mental_models` добавочное: старые чекпоинты читаются без него.
При отсутствии памяти не подмешивается произвольный `mind/mental_models.json`:
это может быть опыт другого имени или более позднего момента. Такой файл
по-прежнему можно импортировать явно; автоматического переноса старого опыта
без согласованного снимка здесь нет. Новая жизнь (`new=True` / `restore=False`)
не наследует память предыдущей. Семя остаётся отдельным явным путём.

Это непрерывность ментальной модели и уже сериализуемого состояния тела,
не обещание полного снимка всех подсистем. Отдельно остаются: восстановление
устойчивых желаний/всех динамических параметров мотивации, выбор более старого
чекпоинта при повреждении последнего и согласованность при параллельных
мутациях из разных потоков. Атомарная публикация файла не является блокировкой
всего состояния существа.

## До / после

```powershell
$env:PYTHONIOENCODING='utf-8'
python tools/manual/restart_continuity_measure.py --report restart.json
```

Инструмент проходит настоящий `create_agent → act → runner.save_now → create_agent`.
Сеть выключена, данные временные. Исходный опыт: отдых при энергии 20 не дал
роста (контролируемая подмена восстановления). Затем создаётся незавершённое
ожидание, выполняется сохранение и повторный запуск.

| Показатель | До | После |
|---|---:|---:|
| Записей опыта до сохранения | 2 | 2 |
| Записей после обычного запуска | 0 | 2 |
| Потерянных записей | 2 | 0 |
| Полное совпадение узла | нет | да |
| Следующее ожидание | рост (+1), опыт забыт | отсутствие роста (-1), опыт учтён |
| Цикл | 17 → 17 | 17 → 17 |
| Энергия | 20 → 20 | 20 → 20 |
| Новая жизнь получила прежний опыт | нет | нет |

Незавершённая попытка не добавила свидетельства, следующая имеет новый id.
Регрессии: `tests/test_restart_continuity.py`, атомарность:
`tests/test_checkpoint_atomicity.py`.
