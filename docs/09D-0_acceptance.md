# Приёмка 9D-0 — базовые социальные каналы

Дата: 2026-11-18.

## Объём и граница результата

Реализован provider-neutral offline-контур каналов, профилей, независимых grants, карантинных входящих реплик и owner-approved проектов. Единственная отправка в проверках выполняется через явно переданный fake adapter.

Реальные соцсети и provider API не подключены. Нет credentials, polling, webhook/polling workers, автономных ответов, публичных действий, автоматического восстановления обмена или Web/команд `send`, `ingest`, `auto`, `resume` для нового контура.

Отчёт sanitized: внешние идентификаторы, содержимое реплик, секреты и живые данные в него не включены.

## Проверенные инварианты

| Область | Фактическая проверка |
| --- | --- |
| Идентичность | Различаются provider, account, conversation и author. Совместимый provider/author повторно использует профиль; одинаковые имена и разные provider/author профили не объединяют. |
| Неизвестный автор | Group-событие без достоверного author получает изолированный unbound unknown-контекст и не может создать проект ответа. |
| Дедупликация и spoofing | Повтор не создаёт вторую реплику или проект. Несовпадающий replay, смена provider/account/scope/author, лишние поля и секретоподобные поля отклоняются до мутации профиля. |
| Карантин | Входящее остаётся `external_social_claim`; injection не меняет Core, цели, локальный профиль, память, grants или разрешения. |
| Grants | По умолчанию каналов и разрешений нет; `receive`, `draft`, `reply` независимы. Изменение grant монотонно повышает версию и снимает прежние approvals. |
| Проекты | Edit возвращает проект в `draft`; новая входящая реплика делает прежний активный проект `superseded`; reject/revoke/stop закрывают pending work без отправки. |
| Exact-scope send | До adapter проверяются approval, SHA-256 точного текста, grant version, канал, conversation scope, reply budget и минимальный интервал. Повторная отправка и несовпадающий receipt не засчитываются. |
| Ошибки adapter | Ошибка санитизируется, не приводит к автоматическому retry и не считается доставкой. |
| Checkpoint | Snapshot строго валидируется до мутаций агента; повреждение откатывается атомарно. Legacy получает пустой закрытый контур. После restart approved становится draft, workers и automatic resume равны нулю/false. |
| Owner-only UI | Web публикует только узкие команды владельца для create/grant/draft/edit/approve/reject/revoke/stop. При другом текущем профиле Core отклоняет управление; standalone без ядра возвращает 503. |
| Сеть и данные | Новый набор блокирует сетевые соединения. Реальные API и живой `data/` не использовались; fixtures остаются синтетическими, revision `9d0-r1`. |
