# Среда самостоятельной деятельности: аудит и порядок подключения

## Что уже есть

- Wikipedia подключена к мышлению, но это не общий поиск и не чтение произвольной страницы.
- Delamain имеет собственный SQLite, чтение/поиск/атомарную запись файлов в workspace.
- EffectorRequest и core-driven driver позволяют исполнять явные планы.
- Обычный когнитивный производитель запросов effector ещё не подключён.
- Процессного sandbox для Python/shell нет. Sandbox Delamain ограничивает пути,
  но не изолирует исполняемый процесс. Нельзя просто добавить туда запуск кода.

## Этапы доступа

1. Подключить явное намерение ядра к существующему EffectorRequest. Первое
   действие — собственная заметка/проект в data/delamain/workspace с проверкой
   результата, без записи в исходники проекта и чужие папки.
2. Общий поиск через выбранного провайдера плюс ограниченный read-only fetch:
   таймауты, лимит ответа, проверка адресов/редиректов, запрет приватных
   сетевых адресов, происхождение данных. Веб-текст не является инструкцией.
3. Отдельный opt-in исполнитель экспериментов с реальной процессной изоляцией,
   лимитами времени/памяти/вывода и без наследования секретов. Не путать
   энергетический бюджет агента с лимитом ресурсов компьютера.
4. Публикации, переписка и внешние изменения — отдельные области разрешений.

Не включать все флаги разом. В текущем конфиге approval mode по умолчанию off;
перед расширением действий выбрать явную политику dangerous/all и исключить
низкоуровневые execute API из модельного dispatch. Аудит не изменял доступы.

## Хранение раньше масштабирования среды

Полные JSON-снимки копировали всю память. Первый шаг миграции — SQLite с
разделяемыми неизменившимися блоками между снимками. Это устраняет многократное
хранение одинакового опыта, но ещё не обеспечивает работу с миллиардом записей.
Дальше нужны ленивое чтение, индексы по смысловым сущностям, горячая/холодная
память и инкрементальная запись без обхода всего состояния.
