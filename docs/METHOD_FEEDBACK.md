# Этап 1: опыт бесплодного способа участвует в выборе

## Изменение

После фильтра доступности, до арбитража, `prepare_candidates()` откладывает
кандидатов с доказанным тупиком. Желания и их исходные предложения не меняются;
в отчёте method_feedback остаются причина и источник отложенного способа.
Рабочие альтернативы сравнивает полноценный арбитр. Поздний loop_closer
сохраняется как страховка от устаревшего/внешнего решения.

Если альтернатив нет, при потребности тела предлагается глубокий отдых,
иначе явный wait с причиной no_working_method. Это пауза, не выполнение
исследовательского намерения и не прирост знания. Влияние второго act(thought)
раннера остаётся: wait не означает полной физической бездеятельности цикла.

## Основание повторной попытки

Фиксируется хеш содержимого knowledge_base, известных определений и
доступности веб-источника. При изменении снимаются тупики продуктивных
способов без отказов тела. Время, энергия, уверенность и счётчик собственных
встреч основанием не являются. Хеш сохраняется в чекпоинте.

Граница: это пока грубый общий информационный контекст. Не проверяется
релевантность нового ответа каждому способу, не распознаётся новая тема
внешнего стимула как отдельное основание. Удаление/изменение знания тоже
меняет контекст. Это ограниченная повторная попытка, не доказательство,
что способ теперь даст результат. Новая неудачная серия снова его отложит.

## Сравнение

Три зерна, 1000 циклов, естественная энергия, перезапуск после 500-го,
сеть выключена, пользователя нет. Контроль — тот же код с отключением
только новой обратной связи через --no-method-feedback. Это экспериментальный
флаг измерителя, не настройка жизни агента. Wall-clock ограничения сохраняются;
одинаковые зерна не гарантируют одинаковую дальнейшую траекторию.

```powershell
python tools/manual/autonomous_life_measure.py --cycles 1000 --seed 1 --no-method-feedback --report before.json
python tools/manual/autonomous_life_measure.py --cycles 1000 --seed 1 --report after.json
```

| Метрика | До, зерна 1/2/3 | После, зерна 1/2/3 |
|---|---|---|
| Поздние замены loop_closer | 644 / 649 / 635 | 0 / 0 / 0 |
| Автономный отдых rest + deep_rest | 736 / 746 / 732 | 376 / 386 / 379 |
| Явная пауза | 0 / 0 / 0 | 387 / 380 / 389 |
| Выполненные продуктивные действия без WorldDelta | 153 / 137 / 156 | 121 / 127 / 126 |
| Продуктивные действия с WorldDelta | 203 / 202 / 192 | 195 / 203 / 180 |

Пустых выполненных продуктивных действий суммарно 446 → 374 (−16%).
При этом эффектов 597 → 578: **повышения обучаемости не показано**.
WorldDelta может учитывать повторную регистрацию опыта: это не оценка
истинности и новизны знания. Доля метки loop_closer сама по себе успехом
не считается.

После: мотивация выигрывает 198/199/197, тело 239/246/239,
Active Inference 123/125/119, общение 23/24/24, проверки 30/26/32.
Во всех перезапусках память, энергия, усталость и кулдаун совпали.
Новых внешних сведений не было: автоматических разрешений повторной
попытки в этих траекториях 0. Разрешение проверено отдельными тестами,
включая восстановление контекста из чекпоинта.

## Вывод

Снята постоянная поздняя подмена решения; разные рабочие альтернативы
снова участвуют в арбитраже. Выявлена реальная пауза при исчерпании способов
в бедной внешними событиями среде. Следующее исследование — релевантный
новый стимул/ответ и возвращение к отложенному намерению, а не искусственное
вытеснение wait случайными занятиями.
