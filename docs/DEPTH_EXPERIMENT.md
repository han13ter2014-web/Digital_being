# Шаг 2: проверка глубины вместо ширины

## Метод

Код поведения — `04b5179`; менялся только `EXPLORATION_DEPTH_RATIO` через
флаг измерителя. 500 циклов, зерна 1–5 для каждой доли, сеть выключена,
энергия удерживается, консолидация включена. Это изолированный эксперимент,
не оценка жизни при естественном энергобалансе и не тест истинности ответов.
Одинаковые зерна задают одинаковые начальные условия, но изменение выбора
действий меняет дальнейшую случайную траекторию.

Воспроизведение (PowerShell, из корня; каталог отчётов должен существовать):

```powershell
$env:PYTHONIOENCODING='utf-8'
foreach ($d in 0.2,0.35,0.5,0.65,0.8) {
    foreach ($s in 1,2,3,4,5) {
        python tools/manual/memory_maturity_measure.py 500 --hold-energy --seed $s --depth $d --report "reports/depth_${d}_${s}.txt" *> $null
    }
}
python tools/manual/depth_sweep_summary.py reports
```

не подтверждена.

## Почему повторения не помогают

Контроль: 0,35, зерно 1, 500 циклов. Все 59 своих понятий имеют определения
и минимум две встречи; в среднем 4,64 встречи. Ответ разрешён для 22.
Из оставшихся 37 с низкой уверенностью **36 не имеют свидетельств вообще**.
Суммарная сила свидетельств по своим понятиям — 14,10.

`ThinkingPipeline._register_unknown_concept()` записывает нейтральный опыт,
если исходный стимул содержит «вопрос». Повторение такого опыта не должно
увеличивать уверенность: агент по-прежнему не получил ответ. Консолидация
может оформить накопленное, но не создать отсутствующие свидетельства.
Кроме того, `_pick_shallow_concept()` перестаёт выбирать тему после трёх
встреч или появления определения: это эвристика незавершённой формулировки,
не оценка содержательного освоения.

## Ограничение метрики и следующий содержательный шаг

Обнаружена отдельная семантическая проблема: та же регистрация без слова
«вопрос» получает valence=0.3 за шаблон «Новая концепция, связана с: ...».
Несколько таких регистраций могут разрешить ответ с тавтологическим
определением. Поэтому **«допущен к ответу» не означает «действительно знает»**;
таблица не доказывает качество или истинность знаний. Увеличивать эту
валентность, снижать пороги или выдавать повторные вопросы за свидетельства
нельзя.

Следующая правка механизма обучения должна разделить регистрацию темы,
собственную гипотезу и содержательное свидетельство с происхождением,
а также проверять содержательность ответа. Здесь такое изменение не сделано:
иначе эксперимент с долей углубления смешался бы с заменой модели знания.
Поведение и пороги не менялись. Добавлены диагностические метрики и тест
того, что восемь нейтральных встреч плюс сон не превращаются в знание.
