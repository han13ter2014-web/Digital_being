# Ожидание → собственное действие → наблюдение → пересмотр

## Реализованный контур

Первый узкий предмет исследования — действие отдыха и собственная энергия.
Это не попытка доказать понимание произвольных понятий по награде.

После выбора действия и разрешения бюджета, но **до исполнения** агент
фиксирует неизменяемое ожидание:

- какое действие он собирается выполнить;
- проверяемое утверждение: «это действие увеличивает мою энергию ниже потолка»;
- энергию и потолок до действия;
- ожидаемое направление результата и прежнюю уверенность;
- уникальный идентификатор попытки.

После исполнения и шага тела сравнивается численное наблюдение энергии.
Текст ответа, успех в арбитре, удовольствие и reward не используются.
Рост поддерживает утверждение; отсутствие роста противоречит ему.
Новое наблюдение получает источник `action:<trial_id>`. Один и тот же
trial нельзя завершить дважды. Незавершённая попытка не становится опытом
на следующем действии.

Следующее ожидание использует накопленное направление свидетельств:
при преобладании опровержений агент ожидает отсутствие роста. Противоречие
снижает уверенность; уверенность в отрицательном выводе отделена от
направления, и ответ из ментальной модели явно помечает опровержение
исходного предположения.

## Что не является отрицательным опытом

- Отказ тела или бюджета: обработчик не исполнялся, ожидание не создаётся.
- Энергия уже на потолке: рост невозможен, такой контекст не проверяет гипотезу.
- Невалидные/нечисловые состояния: свидетельство не создаётся.
- Постороннее действие: не выдаётся за проверку гипотезы об отдыхе.

Неполный запас до потолка допустим: рост 199 → 200 подтверждает направление,
хотя не равен номинальным 12 единицам. Количество восстановления из конфига
не копируется в предсказание — сравнивается наблюдаемое направление.

## Воспроизведение

```powershell
$env:PYTHONIOENCODING='utf-8'
python tools/manual/action_expectation_measure.py --report action_expectations.json
python -m pytest -q tests/test_action_expectations.py
```

Измеритель сравнивает тот же `act('rest')` с отключённой регистрацией ожиданий
и с включённой; затем подменяет восстановление на отсутствие изменения,
не меняя текстовый статус действия. Данные изолированы, сеть не нужна.

### Результат контрольного замера

Два обычных отдыха, затем четыре с подменённым восстановлением (0 энергии).
Перед каждой попыткой энергия 20; физический эффект одинаков с наблюдением
и без него: `[12, 12, 0, 0, 0, 0]`. Без контура — 0 новых переживаний;
с контуром — 7 (исходная гипотеза и 6 наблюдений).

| Попытка | Δ энергии | Ожидание роста | Совпало | Уверенность |
|---|---:|---|---|---:|
| 1 | +12 | да | да | 0,433 |
| 2 | +12 | да | да | 0,767 |
| 3 | 0 | да | нет | 0,367 |
| 4 | 0 | да | нет | 0,100 |
| 5 | 0 | да | нет | 0,260 |
| 6 | 0 | **нет** | **да** | 0,367 |

После трёх противоречащих наблюдений ожидание действительно пересмотрено.
Повышение уверенности после точки 0,100 означает уверенность в отрицательном
направлении, не возврат к исходному утверждению. Отдых на потолке не создал
ни новой попытки, ни свидетельства. Все проверки измерителя прошли.

## Свобода выбора и ограничения

Контур не заставляет отдыхать ради эксперимента: он наблюдает **уже выбранное**
действие. Арбитр, желания, ценности, стоимость и качество действий не меняются.
Первичная гипотеза о росте энергии — заданный эвристический prior,
а не самостоятельно изобретённая теория тела. Последующие ожидания зависят
от собственного опыта.

Это ещё не механизм самостоятельного планирования экспериментов. Пока нет
выбора между действиями по ожидаемой проверяемости, автоматического создания
произвольных гипотез и приписывания результата произвольному утверждению.
Энергетическое наблюдение относится только к этому контексту тела. Его
нельзя переносить на истинность сведений о внешнем мире.

История сохраняется как полный опыт понятия в файле ментальных моделей;
следующее ожидание восстанавливается из неё. Незавершённые ожидания намеренно
не сохраняются как выполненные наблюдения. Автоматическое включение загрузки
ментальных моделей в обычный старт по-прежнему отдельная задача.
