# Явное решение об ожидающем намерении

Предыдущая версия waiting зафиксирована 3ed1964 (1257 passed, 2 skipped).

API resolve_wait(agent, action, target, kind=cancelled/completed, reason)
записывает решение с непустой причиной и циклом. Cancelled не меняет pending
критерий в satisfied и не означает успех. Completed допускается только после
получения свидетельства по существующему критерию. Повторное решение
возвращает already_resolved и не переписывает первую причину.

Запись остаётся в checkpoint; старый журнал, новый общий контекст и очередное
сверение результатов не возобновляют закрытую тему автоматически. Это
сознательная терминальная отметка, а не автоматическое забывание по таймеру.
Обычное исследование этой темы не запрещается: отменён именно возврат по
старому намерению. Явного создания нового поколения намерения той же пары
пока нет, поэтому архив закрытых ключей требует дальнейшего lifecycle.

Границы: API пока не включён в автономный выбор или UI-команды; причины
в тестах задаются вызывающим кодом. Следовательно, это возможность адресного
закрытия, **не доказательство самостоятельного отказа от цели**. Нет
физического архива/удаления: число сохранённых ключей всё ещё может расти.
Не удаляем историю ради заявления о решённом масштабировании. Политика
хранения закрытых записей и явное новое намерение остаются впереди.

Тесты resolution/waiting/relevant/continuation: 10 passed. Проверяются
идемпотентность решения, сохранение причины через apply_state, отсутствие
возобновления отменённой темы и запрет completed без свидетельств.
