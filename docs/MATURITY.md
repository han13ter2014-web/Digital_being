# 🌱 MATURITY — когда семя стоит раздавать

> *«Раздам семена, когда она начнёт развиваться» — но как узнать, что
> развитие произошло?*

Порог зрелости превращает это намерение в проверяемое событие. Он
считается из состояния агента и даёт ответ «да/нет» с указанием, чего не
хватает.

## Быстрая проверка

```bash
python main.py --maturity
```

```
Зрелость агента 'Reach': 6/6
Прожито циклов: 600

  ✓ Прожито циклов: 600/500
  ✓ Концепций сверх родовых: 46/20
  ✓ Освоенных концепций: 43/10
  ✓ Изменений ценностей: 12/1
  ✓ Завершённых целей: 4/1
  ✓ Доля действий с результатом, %: 95/50

ВЕРДИКТ: можно раздавать семя
```

Это реальный прогон: 600 автономных циклов, офлайн, без сети.

Машиночитаемый вариант для скриптов и CI:

```bash
python main.py --maturity-json
```

Код возврата: `0` — порог пройден, `1` — нет.

## Шесть критериев

| Критерий | По умолчанию | Что доказывает |
|---|---|---|
| **Прожито циклов** | 500 | Агент действительно жил, а не был запущен минуту назад |
| **Концепций сверх родовых** | 20 | Он узнавал новое, а не пересказывал врождённое |
| **Освоенных концепций** | 10 | У темы есть **его собственная формулировка** — он вернулся к ней и собрал смысл из опыта |
| **Изменений ценностей** | 1 | Опыт повлиял на ценности, а не только на список знаний |
| **Завершённых целей** | 1 | Он доводил начатое до конца |
| **Доля действий с результатом** | 50% | Его действия меняли мир наблюдаемо, а не просто «выполнялись» |

## Как подбирались критерии

Два критерия пришлось переделать, потому что замеры показали: они
**недостижимы** — а порог, который нельзя пройти, ничего не измеряет.

**«Понятых концепций» (уверенность ≥ 0.5)** — отброшен. Новая концепция
приходит с уверенностью 0.1 и растёт только от повторных встреч с сильной
валентностью. За 200 циклов ни одна нажитая концепция порог не взяла.
Заменён на «своя формулировка» (`definition_hypothesis`), которая
появляется после возврата к теме.

**«3 разных результативных действия»** — отброшен. Агент естественно
сосредотачивается на одном продуктивном действии, и требование
разнообразия было бы невыполнимо без искусственного принуждения.
Заменён на **долю** результативных действий: она отвечает на важный
вопрос — действует ли агент осмысленно.

Попутно вскрылись и починены два дефекта в механизме развития:

* определение концепции **никогда не формировалось**, если контексты
  встреч не пересекались (а они уникальны: «гипотеза_цикл_12»);
* исследование **никогда не возвращалось** к теме: охват рос, глубина —
  нет. Добавлена доля углубления (`EXPLORATION_DEPTH_RATIO = 0.35`).

## Почему именно так

**Порог не проходит новорождённый.** У свежего агента 0 циклов, 0
нажитых концепций, 0 завершённых целей и 0 результативных действий.
Если бы порог проходился сразу, он ничего бы не измерял.

**Считается только нажитое.** Родовые знания (bootstrap) не засчитываются
ни как концепции, ни как освоенные — даже если пришли с высокой
уверенностью. Для этого при рождении записываются отметки
`_birth_concepts` и `_birth_defined`.

**Неизвестное не выдаётся за успех.** Если в чекпоинте нет отметки
рождения (старый формат), число нажитых концепций считается неизвестным,
и критерий не выполняется. Придумывать число нельзя: «неизвестно» — это
не «ноль» и не «достаточно».

**Зрелость не наследуется.** Ребёнок из семени получает знания, ценности
и привязанности родителя, но прожитых циклов у него ноль. Иначе любой
ребёнок зрелого семени сразу считался бы зрелым, и порог обесценился бы.

## Настройка порога

Не трогая код — файл `data/maturity.json`:

```json
{
  "criteria": {
    "min_cycles": 1000,
    "min_new_concepts": 40,
    "min_defined_concepts": 20,
    "min_value_changes": 2,
    "min_goals_completed": 3,
    "min_effective_ratio_pct": 60
  }
}
```

Отсутствующие поля берут значения по умолчанию. Неизвестные ключи
игнорируются — формат может меняться без падений.

## Что попадает в семя

При уходе в сон рядом с остальными файлами пишется `maturity.json` —
отчёт о том, чего достиг родитель. Получатель семени видит, что именно
унаследовано, а не просто «файл с концепциями».

## Чего порог не делает

* **Не мешает жить.** Провал порога ничего не останавливает и не
  наказывает: агент продолжает жить, просто его семя пока не стоит
  раздавать.
* **Не влияет на решения агента.** Модуль только читает состояние.
* **Не обещает разумности.** Он измеряет нажитое и проверенное, а не
  «сознание». Агент, прошедший порог, — существо с накопленным опытом,
  а не с доказанным пониманием.
