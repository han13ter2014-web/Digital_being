# Канонический статик-конвейер

## Канон

Единственный канонический статик Digital Being — **ruff из pre-commit-кэша**,
запускаемый хуками `ruff` и `ruff-format` из `.pre-commit-config.yaml`.
Текущая версия: **0.5.7** (`rev: v0.5.7`).

Путь бинаря на Windows имеет вид:

```
%USERPROFILE%\.cache\pre-commit\repo<hash>\py_env-python3\Scripts\ruff.exe
```

## Почему не локальные версии ruff

Локально установленный ruff (например, 0.17.4 из pip) каноном **не является**.
Один и тот же файл получил разные вердикты от ruff 0.5.7 (pre-commit) и
ruff 0.17.4 (локальная установка) — рассинхрон версий делает вердикты
статика невоспроизводимыми. Проверки всегда запускают ruff именно из
pre-commit-кэша; локальный pip-бинарь для вердиктов не используется.

## Как обновить версию ruff

Менять в ОДНОМ коммите, одновременно:

1. `rev` в `.pre-commit-config.yaml` (репозиторий `astral-sh/ruff-pre-commit`);
2. пин в dev-зависимостях `pyproject.toml` → `[project.optional-dependencies] dev`
   (`ruff==<версия>`).

Контроль рассинхрона — мета-тест `tests/test_static_pin.py`:
он парсит оба файла и падает, если версии после нормализации префикса `v`
расходятся.
Мета-тест требует **PyYAML** (явная строка `"PyYAML>=6"` в dev-группе
pyproject.toml); в средах без него тест скипается на уровне модуля, и скип
виден в счётчиках проверки.

## Исторический формат-дрейф

Аудит установил: канон `ruff-format` (rev v0.5.7 — в конфиге с первого
коммита `1a00eed`) фактически **не применялся** к части дерева до закрепления
единой версии. Пример: `src/delamain/llm_planner.py` создан в `29b8fb2`
(stage10, 2026-10-21) уже в неканоническом формате (`ruff format --check`
на той версии — `Would reformat`); два хунка пережили пять последующих
коммитов (`da51037`, `7e70325`, `e4b351d`, `7ee8500`) и были нормализованы
отдельно. Blame подтвердил, что строки сохранялись с момента создания файла.
Вывод: хуки локально не исполнялись (или обходились) — конфиг был, прогона
не было.

Следствие для ревизий: при первом касании давно не тронутого файла канон
может потребовать «чужой» формат-дифф. Такая нормализация выносится в
отдельный format-only коммит без логических изменений, чтобы не смешивать
формат с семантикой.
