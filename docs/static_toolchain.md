# Канонический статик-конвейер

## Канон

Единственный канонический статик Digital Being — **ruff из pre-commit-кэша**,
запускаемый хуками `ruff` и `ruff-format` из `.pre-commit-config.yaml`.
Текущая версия: **0.5.7** (`rev: v0.5.7`).

Путь бинаря на Windows имеет вид:

```
%USERPROFILE%\.cache\pre-commit\repo<hash>\py_env-python3\Scripts\ruff.exe
```

## Почему не локальные версии ruff

Локально установленный ruff (например, 0.17.4 из pip) каноном **не является**.
Инцидент k16-37: один и тот же файл получил разные вердикты от ruff 0.5.7
(pre-commit) и ruff 0.17.4 (локальная установка) — рассинхрон версий делает
вердикты статика невоспроизводимыми. Гейты тикетов всегда гоняют ruff
именно из pre-commit-кэша; локальный пип-бинарь для вердиктов не используется.

## Как обновить версию ruff

Менять в ОДНОМ коммите, одновременно:

1. `rev` в `.pre-commit-config.yaml` (репозиторий `astral-sh/ruff-pre-commit`);
2. пин в dev-зависимостях `pyproject.toml` → `[project.optional-dependencies] dev`
   (`ruff==<версия>`).

Контроль рассинхрона — мета-тест `tests/test_static_pin.py` (k16-38):
он парсит оба файла и падает, если версии после нормализации префикса `v`
расходятся.
Мета-тест требует **PyYAML** (с k16-38-amend это явная строка `"PyYAML>=6"`
в dev-группе pyproject.toml); в средах без него тест скипается на уровне
модуля, и скип виден в счётчиках гейта.
