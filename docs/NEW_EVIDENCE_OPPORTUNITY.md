# Новая возможность в офлайн-среде: ответ человека

Сравниваются отсутствие источника, настоящий принятый ответ по другой теме
и по нужной теме. Намерение «получить свидетельство о памяти» и его первая
безрезультатная повторная попытка задаются через API; это контролируемая
проверка, не естественное рождение желания и не замер предпочтений арбитра.
Wikipedia выключена, ответы принимает настоящий UserInteraction/ThinkingPipeline.

```powershell
python tools/manual/new_evidence_measure.py --report new_evidence.json
```

До исправления: релевантный ответ сохранял testimony в ментальной модели,
но ожидающее намерение оставалось pending. Общий information_context
(KB/definitions/web) при этом не менялся: данный путь ответа записывает
ментальную модель, не KB. Проводка продолжения не замечала выполненную цель.

После: при подготовке продолжений pending evidence-goal сверяется с
источниками именно выбранной темы. Релевантный новый источник переводит
узкую цель в satisfied, другой ответ не завершает её. Повторный explore
не требуется только ради галочки возврата. Без источника остаётся pending.

| Условие | Новое свидетельство о памяти | Статус | Повторное исследование |
|---|---|---|---|
| Нет источника | нет | pending | не предлагается после неудачной попытки |
| Ответ о дереве | нет | pending | не предлагается |
| Ответ о памяти | да | satisfied | не требуется |

В окончательном контроле тема уже встречена без свидетельства; релевантный
ответ становится второй встречей, и think('вопрос: память') возвращает
[Ментальная модель]. Это демонстрирует использование полученной формулировки,
не оценку истинности произвольного ответа. На совсем новом узле одна встреча
ещё не проходит существующий порог can_answer_about; порог не менялся.

Набор relevant/evidence/continuation/history/profile: 15 passed.
Новые материалы не обязаны немедленно вызывать действие: здесь они уже
исполняют узкий критерий. Продолжение более широкой цели «разобраться»
ещё не определено. Сверка мутирует статус сохранённой попытки при подготовке
кандидатов; отдельного события удовлетворения с причиной/временем пока нет.
