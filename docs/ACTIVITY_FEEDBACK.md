# Обратная связь соответствует занятию, не имени алиаса

Play.related_actions теперь play/creative_act: исследование, синтез,
воспроизведение ответа не считаются игрой. Из обратного моста explore и
synthesis убран creative_act. Настоящий create_draft имеет отдельный мост
к creative_act, play — к play. Default больше не притворяется исследованием,
рефлексией и постановкой цели одновременно; неопределённый акт не закрывает
насущные потребности. Порогов и приоритетов не меняли.

Старый общий тест «каждое действие удовлетворяет потребность» уточнён для
default, который означает нераспознанный тип, а не полезную деятельность.
Отдельный отрицательный тест проверяет отсутствие изменения всех needs за
такой акт, поэтому уточнение не скрывает потерю обратной связи.

Адресный набор activity_feedback/motivation/play/creative choices/profile:
60 passed. Прямой контроль on_action_result(True, 0.8) показывает:
research/synthesis/recall/hypothesis/default не удовлетворяют play;
реальные play/create_draft удовлетворяют play и не награждают curiosity.
Это контроль маршрутизации сигнала, не субъективная оценка удовольствия.

Границы: synthesis всё ещё может обслуживать competence/meaning и общение
через teach_other — их семантика ещё требует проверки. Игра может быть
познавательной, но это должно следовать из отдельного наблюдения, не alias.
Оценка actual_valence пока эвристическая, универсальный структурированный
outcome ещё впереди. Изменения DEFAULT_NEEDS не перезаписывают сохранённые
уровни потребностей; текущий loader берёт related_actions из действующего
конфига. Глубокие и общие прогоны этого малого участка не запускались.
